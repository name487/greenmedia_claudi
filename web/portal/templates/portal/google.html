One-time setup needed on the API server

Not configured
  1. In Google Cloud Console, create a project and enable: My Business Account Management API, My Business Business Information API, Google My Business API, Business Profile Performance API.
  2. Request Business Profile API access for the project (Google approves it; until then quota is 0).
  3. Create an OAuth client ID of type Web application with authorized redirect URI {{ status.redirect_uri }}.
  4. Set GOOGLE_CLIENT_ID, GOOGLE_CLIENT_SECRET, GOOGLE_REDIRECT_URI, WEB_APP_URL and TOKEN_ENCRYPTION_KEY in backend/.env and restart the API.

Getting “Error 400: redirect_uri_mismatch” from Google?

Add this exact address under Authorized redirect URIs on the OAuth client in Google Cloud (APIs & Services → Credentials), save, and wait ~5 minutes:

{{ status.redirect_uri }}

It must match character for character — localhost vs 127.0.0.1, http vs https, the port and a trailing slash all count. To change it, set GOOGLE_REDIRECT_URI in backend/.env and restart the API. When Google asks, sign in with the account that manages the Business Profiles.
